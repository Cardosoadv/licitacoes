🚀 Início Rápido

Pré-requisitos: PHP 8.1+, MySQL 8.0+, Composer

1. Navegar até o projeto:

cd d:\codes\xampp\licitacoes

2. Instalar dependências:

composer install

3. Configurar ambiente (já feito):

cat .env | grep DATABASE

4. Iniciar servidor:

php spark serve

5. Acessar aplicação:

http://localhost:8080

6. Sincronizar licitações:

php spark licitacoes:sync 7
